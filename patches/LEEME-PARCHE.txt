Plot Mundial — parches aggiornati
=================================

1) Código (Git)
   Archivo: plot-mundial-codigo-aggiornato.patch
   Contiene: diff desde el commit inicial (9271622) hasta HEAD — footer, home,
   dashboard (pronósticos/ligas), middleware, Vercel, etc.

   Aplicar en un clon limpio del mismo repo:
     git checkout 9271622
     git apply patches/plot-mundial-codigo-aggiornato.patch

   O integrar sobre main existente (puede fallar si ya tenés los mismos cambios):
     git apply --3way patches/plot-mundial-codigo-aggiornato.patch

2) Base de datos (Supabase SQL Editor)
   Un solo archivo (recomendado): supabase/plot-mundial-todo-en-uno.sql
      = borrado + schema + seed en una sola ejecución.

   Alternativa en dos pasos:
   a) supabase/PLOT_MUNDIAL_RESET.sql
   b) supabase/plot-mundial-schema-aggiornato.sql

   Si los usuarios ya existían en Auth sin fila en profiles, al volver a
   registrarse o con un script manual habría que alinear perfiles.
